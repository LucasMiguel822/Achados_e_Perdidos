🔎 Achados e Perdidos
📌 Sobre o Projeto
O Achados e Perdidos é um projeto de sistema web e mobile desenvolvido para organizar e facilitar o processo de registro, localização e devolução de objetos perdidos, especialmente em ambientes de grande circulação, como escolas.

O sistema busca substituir os registros manuais por uma plataforma digital que permite consultar objetos encontrados, solicitar sua retirada e controlar a devolução presencial no balcão de atendimento.

O projeto foi desenvolvido como parte do Projeto de Tecnologia da Informação e Comunicação (PTIC), do curso de Desenvolvimento de Sistemas da Etec Cidade Tiradentes.

🚀 Tecnologias e Recursos
Sistema web e mobile: proposta de acesso ao sistema por navegadores e dispositivos móveis.
Catálogo digital: consulta dos objetos encontrados.
QR Code: acesso ao catálogo público.
Protótipos de interface: representação das telas e funcionalidades do sistema.
Git e GitHub: armazenamento e versionamento dos arquivos do projeto.
✨ Funcionalidades
Consultar catálogo: permite pesquisar objetos disponíveis utilizando uma barra de pesquisa e filtros por categoria, núcleo e dados.
Cadastrar objetos: registre informações como nome, categoria, cor, foto, dados e local onde o objeto foi encontrado.
Validar coleta: permite conferir e confirmar a coleta de objetos no balcão.
Solicitar retirada: permite que uma pessoa solicite a devolução de um objeto que acredita ser seu.
Registrar saída: registrar a entrega do objeto após a conferência presencial das informações do solicitante.
Cadastrar funcionários: permite que o gerente crie contas para os funcionários.
Consultar relatórios: apresenta detalhes de objetos recebidos, disponíveis e devoluções em determinado período.
Controlar acessos: diferenciar as permissões de funcionários e gerentes.
👥 Usuários do Sistema
Perdedor: pessoa que perdeu um objeto e procura por ele no catálogo público.
Achador: pessoa que encontrou um objeto e o entregou para registro.
Funcionário (Operador): responsável por cadastrar objetos, consultar registros e confirmar as devoluções.
Gerente: responsável pelo cadastro de funcionários e pela consulta de relatórios gerenciais.

🔄 Funcionamento do Sistema
Um objeto encontrado é entregue no balcão de atendimento.
O funcionário registra as informações do objeto no sistema.
O objeto fica disponível no catálogo público, acessível pelo site ou QR Code.
Uma pessoa que perdeu o objeto consultado no catálogo e solicitou sua retirada.
No balcão, o funcionário verifica as informações apresentadas pelo solicitante.
Após a validação, o objeto é entregue e seu status é atualizado para Devolvido .
🔐 Segurança e Confiabilidade
O projeto prevê autenticação para as áreas internas, controle de acesso por perfil, validação das informações antes da devolução e registro das entradas e saídas dos objetos.
